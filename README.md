# AayaamX Technologies

A product-engineering homepage built with Next.js App Router, React 19, TypeScript, Tailwind CSS, Three.js, React Three Fiber, Drei, GSAP/ScrollTrigger, Framer Motion and Lucide.

## Run

npm install
npm run dev

Open http://127.0.0.1:3207. Production build: npm run build. Type check: npm run typecheck.

## The live product engineering system

One persistent 3D canvas shows four connected modules in an open studio composition without a platform:

- AI: rotating neural graph on a processing chip.
- Trading infrastructure: animated three-dimensional candlesticks and data services.
- Blockchain: interconnected distributed ledger blocks.
- Product engineering: layered application interfaces and software components.

An elevated blue-and-green glass infinity core with studio environment reflections connects the ecosystem. Selecting a capability moves that module to the foreground at 1.95 scale while supporting modules use 0.55 scale through a 1.5-second GSAP transition; the objects and canvas stay mounted. Data packets follow physical routes from modules to the core. Pointer parallax and scroll movement add restrained depth.

The automatic delivery sequence changes the actual 3D system: progressive architecture connections, staggered component assembly, accelerated deployment flows and continuous operational pulses. Delivery stages advance every 1.5 seconds. Capability autoplay advances every 6 seconds and waits 12 seconds after manual interaction.

Pause stops idle motion and autoplay. Reduced motion disables autoplay and idle movement, with immediate manual transitions. Hidden tabs stop rendering. Mobile uses lower pixel density and half the data particles. Projected labels share the main React tree. Geometries, listeners and GSAP timelines are cleaned up.
